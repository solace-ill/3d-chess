# Pyramid 3D Chess Prototype

ピラミッド状に積み上げた盤面で遊ぶ 3D チェスの HTML プロトタイプです。

通常のチェス盤を 3 次元に拡張し、駒の移動も `x`, `y`, `z` の 3 軸で扱います。今後、新しい種類の駒を追加しやすいように、各駒の移動ルールは `index.html` 内の `pieceTypes` にまとめています。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 自分の手番の駒をクリックします。
3. 緑のマーカーが移動可能マス、赤のマーカーが捕獲可能マスです。
4. 移動先のマス、または捕獲対象の敵駒をクリックすると移動します。
5. 右側の `Moves` に棋譜が追加されます。

駒を選択すると、その駒の足元に金色のリングが表示されます。カメラの回転中心も選択した駒に移るので、そのままドラッグすると選択中の駒を中心に盤面を見回せます。

## 盤面

盤面は 4 層のピラミッドです。

| Layer | Footprint | 有効マス |
| --- | --- | --- |
| L1 | 8 x 8 | 上層に覆われていない外周 |
| L2 | 6 x 6 | 上層に覆われていない外周 |
| L3 | 4 x 4 | 上層に覆われていない外周 |
| L4 | 2 x 2 | 全マス |

座標は `L階層:列行` で表示します。例: `L2:b2`

重要なルール:

- 上から見えている段マスだけが有効です。
- 上の階に覆われている内側のマスは存在しない扱いです。
- 存在しないマスには移動できません。
- 直線移動の駒も、存在しないマスを通過できません。

## 駒の動き

このプロトタイプではチェック、チェックメイト、キャスリング、アンパッサン、昇格はまだ実装していません。まずは 3D 盤面上の移動と捕獲を確認するためのルールです。

### King: `K`

`x`, `y`, `z` の各方向に最大 1 マス動けます。

2D チェスのキングに、上下階への 1 マス移動と 3D 斜め移動を加えた形です。

例:

- `x + 1`
- `y - 1`
- `z + 1`
- `x + 1, y + 1, z + 1`

### Queen: `Q`

Rook, Bishop, Unicorn の動きをすべて合わせた駒です。

次の直線方向に、遮られるまで何マスでも動けます。

- 単軸直線
- 2 軸斜め
- 3 軸斜め

### Rook: `R`

1 つの軸だけを変えて、遮られるまで何マスでも動けます。

方向:

- `x` 軸: 左右
- `y` 軸: 前後
- `z` 軸: 上下階

例:

- `x + n`
- `y - n`
- `z + n`

### Bishop: `B`

2 つの軸を同じ距離だけ変えて、遮られるまで何マスでも動けます。

方向:

- `x` と `y`
- `x` と `z`
- `y` と `z`

例:

- `x + n, y + n`
- `x - n, z + n`
- `y + n, z - n`

### Unicorn: `U`

3D チェス用の追加駒です。

3 つの軸すべてを同じ距離だけ変えて、遮られるまで何マスでも動けます。

例:

- `x + n, y + n, z + n`
- `x + n, y - n, z + n`
- `x - n, y - n, z - n`

### Knight: `N`

3D の L 字移動をします。

3 軸の移動距離が `2`, `1`, `0` の組み合わせになる場所へジャンプします。通常のナイトと同じく、途中のマスは無視します。

例:

- `x + 2, y + 1, z + 0`
- `x + 2, y + 0, z - 1`
- `x + 0, y - 2, z + 1`

### Pawn: `P`

前方へ 1 マス進みます。

白は `y + 1`、黒は `y - 1` が前方です。

移動:

- 前方 1 マスが空いていれば移動できます。
- 前方 1 マスかつ 1 階層上または下のマスが空いていれば移動できます。

捕獲:

- `x` が 1 つ横、`y` が前方 1 マスの敵駒を取れます。
- さらに白は `z + 1`、黒は `z - 1` の斜め階層方向も捕獲対象です。

## 捕獲

合法手の中に敵駒がいる場合、そのマスには赤いマーカーが表示されます。

捕獲するには、選択中の状態で次のどちらかをクリックします。

- 赤いマーカーのあるマス
- そのマスにいる敵駒

味方の駒がいるマスには移動できません。直線移動の駒は、最初にぶつかった駒で止まります。その駒が敵なら捕獲可能、味方ならそこでブロックされます。

## 新しい駒を追加する場所

`index.html` の `pieceTypes` に新しい定義を追加します。

必要な主な項目:

- `symbol`: 盤面ラベル
- `shape`: 表示形状
- `color`: 台座やアクセント色
- `moves`: 合法手を返す関数

既存の補助関数:

- `rayMoves(from, directions, color)`: 直線移動用
- `stepMoves(from, directions, color)`: 固定距離移動用
- `axisDirections()`: 単軸方向
- `planeDiagonalDirections()`: 2 軸斜め方向
- `spaceDiagonalDirections()`: 3 軸斜め方向
